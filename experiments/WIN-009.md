# WIN-009 - Local Constellation

## Purpose

Authenticated local discovery, pairing, commands, handoff and optional relay integration.

This file is a specification. It does not assert that the experiment is
implemented, shipped, installed or hardware-qualified.

## Requirements

Documented LAN APIs and two explicitly consenting peers for live qualification. Relay hosts, tunnels and third-party infrastructure are optional separate integrations, not automatic installation dependencies.

Verify current official SDK/API deployment floors before selecting dependencies.
Pin the actual toolchain and keep optional/preview requirements isolated.

## Runtime probes

Read local-network availability/permission and identify compatible peers. Discovery is not authentication. Network listener starts only from an explicit operation.

Publish a `CapabilityReadiness` reason and fallback. Readiness probes never
prompt, download, start recording/listening/output or alter system settings.

## Meaningful fallback

Local actions and manual pairing; keep current owner running when a handoff fails.

## Bounded experiment

Pair two isolated sample apps with a short-lived code, protect per-peer keys, send bounded commands with replay protection, and transfer one synthetic session only after receiver acknowledgement. Optional relay identifies actual documented capture/encode/transport/audio paths.

Bind operations to IDs and exact request fingerprints. Use bounded memory/time,
explicit cancellation and honest failed/rejected outcomes. Do not publish partial
output or silently replay a side effect on a duplicate request. The foundation's
in-memory ledger is not a durable/network exactly-once guarantee.

## Fault and transition cases

Bad/expired code; replay; wrong peer; oversized body; rate flood; timeout; duplicate delivery; key rotation; disconnect; receiver rejects; sender retains ownership.

## Acceptance and evidence

W0 covers protocol/security/rate/cap bounds. W4 proves real authenticated local peer and failed-handoff behavior. W6 measures actual end-to-end operation/relay latency where used. No credentials in URI/QR/log; public internet exposure is not a default.

Record exact commit/toolchain/architecture/package when relevant, fixture and
asset provenance/hash, capability state, operation IDs/outcomes, commands,
inspected captures, measured costs and unverified paths. Measurements use actual
operations and monotonic clocks/profilers, not replay timestamps. Sanitize receipts;
raw inventories/captures/models remain ignored. Never include account/host/user
identity, serials, credentials or confidential consumer content.
